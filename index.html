Set up Firebase Sign-In & Cloud Save

One-time setup, done by whoever owns this file

This app is a static site with no server of its own, so cloud save needs a free Firebase project before it will work. It also only works when the file is opened over http:// or https:// (e.g. hosted on GitHub Pages, Netlify, or your own site) — sign-in is not allowed on a file opened directly from disk (file://).
1

Create a Firebase project

Go to console.firebase.google.com, click Add project, name it (e.g. "Yash Finance"), and finish the wizard. You can leave Google Analytics off — it isn't needed here.

2

Register a Web app

On the project overview page, click the </> (Web) icon to add a web app. Give it a nickname and click Register app. You don't need Firebase Hosting for this step.

3

Copy the config object into this file

Firebase shows a code snippet with a firebaseConfig object (apiKey, authDomain, projectId, etc). Open script.js in a text editor, find const firebaseConfig = { ... } near the top of the "FIREBASE SIGN-IN" section, and replace each placeholder value with the matching one from Firebase.

4

Enable Google as a sign-in method

In the Firebase console sidebar go to Build → Authentication → Get started, open the Sign-in method tab, click Google, toggle it Enable, pick a support email, and save. Firebase sets up the OAuth client for you automatically — no separate Google Cloud Console step needed.

5

Create a Firestore database

Sidebar → Build → Firestore Database → Create database. Choose a location close to you and start in test mode for now — you'll lock it down in the next step.

6

Restrict access with a security rule

In Firestore's Rules tab, replace the contents with the rule below and click Publish. This makes sure each signed-in person can only ever read or write their own saved data:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /yashFinancePortals/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

7

Add your hosted site as an authorized domain

Back in Authentication → Settings → Authorized domains, add the domain where you'll host this file (e.g. yourname.github.io) — domain only, no https:// and no path.

8

Host it and reload

Upload the files to the domain you added in step 7, open it there, and click Sign in with Google. Once signed in, the cloud save/load icons in the header will save and load your data through Firestore.
